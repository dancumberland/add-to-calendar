The Nov 29 analytics refactor (commit `06f8179`) corrupted `api/calendar-block/index.js`:

**Before (broken):**
```javascript
// Usage tracking functions

  try {
    const today = new Date().toISOString().split('T')[0];
    const key = `usage:${today}`;
  if (text.includes('meeting') || ... // ORPHANED CODE - no function wrapper
  return 'other';
```

**Problems:**
1. Incomplete `trackUsage()` stub left behind (missing try/catch closure)
2. `inferEventType()` function never defined - code fragments were orphaned
3. Line 180 called `inferEventType(title, description)` which didn't exist

### Why App Still Worked

The tracking call is inside a try/catch block (lines 175-187):
```javascript

  await trackDailyUsage({
    ...
```

Users got working calendar buttons, but tracking silently failed for ~1 week.

### 2. Fixed the Code
Replaced corrupted code with proper `inferEventType()` function:

```javascript
// Infer event type from title/description for analytics
function inferEventType(title, description = '') {
  const text = `${title} ${description}`.toLowerCase();
  if (text.includes('meeting') || text.includes('call') || text.includes('zoom')) return 'meeting';
  if (text.includes('appointment') || text.includes('doctor') || text.includes('dentist')) return 'appointment';
  if (text.includes('birthday') || text.includes('anniversary')) return 'personal';
  if (text.includes('deadline') || text.includes('due') || text.includes('submit')) return 'deadline';
  if (text.includes('event') || text.includes('conference') || text.includes('workshop')) return 'event';
  return 'other';
}
```
