# Dashboard History Paging

**Date**: 2026-10-02
**Status**: Implementation complete; fixture UI verified in isolated Chromium; production deployment not performed.

## Request

Extend the Add-to-Calendar for Kit admin dashboard with selectable 8-week, 12-week, 24-week, and 1-year chart ranges, plus previous/next paging through completed-week history.

## Changes

- Added a history-aware analytics query that fetches weekly aggregate keys for the selected date window, falls back to daily metrics while they are retained, and excludes the current partial week.
- Added range selection and older/newer page controls, clear ISO date boundaries, page indicators, disabled navigation at both ends, and empty/unretained-data messaging.
- Kept the summary cards fixed to the latest two completed weeks so historical chart paging does not change their meaning.
- Preserved the dashboard's existing `?secret=` authorization and used GET navigations for range/page changes. Added a no-referrer response policy so the dashboard URL is not sent to the Chart.js CDN as a referrer.
- Documented the 365-day weekly aggregate and 30-day daily detail retention limits. Expired weekly aggregates are chart gaps, not misleading zeroes.
