3. **Outlook redirecting to join page** - Enterprise/work users being redirected to create personal Outlook accounts

## Root Cause Analysis

### Issue 1: Outlook Date/Time Format

**Root Cause**: Using Google's date format for Outlook URLs.

The code was using `formatDateForGoogle()` for Outlook, which produces:
```
20250128T180000Z  (compact format without separators)
```

But Outlook's deeplink requires proper ISO 8601 format:
```
2025-01-28T18:00:00Z  (with hyphens and colons)
```

### Issue 2: iCal Download Attribute

**Root Cause**: The `download="invite.ics"` attribute on the Apple link was conflicting with the API response headers in some email clients/browsers.

The server already sets `Content-Disposition: attachment` header, so the download attribute was redundant and potentially problematic.

### Issue 3: Outlook Work Accounts

**Root Cause**: Only using `outlook.live.com` (consumer endpoint) which doesn't work for Office 365/enterprise users.

Enterprise users with work Microsoft accounts need to use `outlook.office.com` instead.

## Implementation

### Changes Made

**File**: `api/calendar-block/index.js`

1. **Fixed timezone date-shift bug** (line 123-127):
```javascript
// Before: Parsed in target timezone, causing date to shift back one day for western timezones
const datePart = DateTime.fromISO(dateISO, { zone: ianaTimezone }).toISODate();

// After: Extract date directly from ISO string to preserve user's selected date
const datePart = dateISO.split('T')[0];
```

2. **Added Outlook-specific date formatter** (line 190-191):
```javascript
const formatDateForOutlook = (dt) => dt.toUTC().toISO({ suppressMilliseconds: true });
```

2. **Updated Outlook URL to use correct format** (line 216-217):
```javascript
outlookUrl.searchParams.set("startdt", formatDateForOutlook(startDateTime));
outlookUrl.searchParams.set("enddt", formatDateForOutlook(endDateTime));
```

3. **Added Office 365 endpoint** (lines 219-227):
```javascript
const office365Url = new URL("https://outlook.office.com/calendar/deeplink/compose");
// ... same parameters as Outlook, same ISO 8601 format
```

4. **Removed download attribute from Apple link** (line 316):
```html
<a href="${icsUrl}" style="${buttonStyle}">Apple</a>
```

5. **Added Office 365 button to HTML output** (lines 321-323):
```html
<td style="padding: 0 5px;">
  <a href="${office365Url}" style="${buttonStyle}">Office 365</a>
</td>
```

### Automated Testing System

Created new files:

**`api/test-calendars/index.js`**:
- Test endpoint that validates all calendar URL formats
- Tests timezone handling with multiple scenarios
- Validates ICS file generation
- Tests Vercel KV connection
- Returns JSON results with pass/fail status

- CLI script to run tests manually
- Sends email alerts on failure via Make.com webhook

**`package.json`** (updated):
