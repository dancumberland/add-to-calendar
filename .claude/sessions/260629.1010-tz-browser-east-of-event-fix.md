# Kit Calendar — Timezone fix: browser east of event TZ (Bug 6)

## Summary
Kit (Trung) reported a Helsinki-browser creator who set an event to London and picked July 14 seeing July 13. Root cause: the old `max(utcDate, tzDate)` date recovery is blind to "browser east of event tz" — both operands land a day early. Generalized the fix (not London-only), extracted the parser to a shared module, added watchdogs, deployed, verified, and sent Trung a reply.
