## Context
Sharon (Brisbane, Australia) reported that while the date-off-by-one bug was fixed, she couldn't find Brisbane in the timezone dropdown. She sent a video showing her scrolling through the list — Brisbane/Queensland wasn't there.

Previous session (260204) had added Brisbane to our backend `TIMEZONE_MAP`:
```javascript
'Brisbane (GMT+10:00)': 'Australia/Brisbane',
'Queensland (GMT+10:00)': 'Australia/Brisbane',
```

But this mapping never gets triggered because users can't select Brisbane from Kit's dropdown in the first place.

## Objectives
1. Understand why Brisbane isn't appearing in the timezone dropdown
2. Determine if we can fix it on our end
3. Provide a path forward for Sharon

## Investigation Details

### Initial Hypothesis
Assumed the timezone dropdown was a `select` field we controlled in our app's settings JSON configuration.

### Research Conducted
1. Read Kit developer docs thoroughly:
   - Plugin configuration: https://developers.kit.com/plugins/content-blocks/plugin-configuration
   - Plugin settings: https://developers.kit.com/plugins/content-blocks/plugin-settings
   - Component library: https://developers.kit.com/plugins/component-library/overview
   - Select input: https://developers.kit.com/plugins/component-library/select-input
   - Kit's JSON schema validator

2. Reviewed Kit's supported component types:
   - `color`, `date`, `fontFamily`, `group`, `number`, `radioGroup`, `search`, `select`, `slider`, `textarea`, `text`, `toggle`
   - **No native `timezone` type documented**

3. Reviewed session history (250930, 251001, 251013):
   - Kit sends timezone as IANA strings like `"Asia/Dubai"`
   - The dropdown is Kit's native UI component
   - Our code receives whatever Kit sends

### Key Finding
The timezone dropdown Sharon sees is **Kit's platform UI**, not a component we configure. It's built into Kit's editor and the list of available timezones is controlled by Kit, not app developers.

From screenshot analysis: The dropdown shows "Select an option" in Kit's standard UI styling with city names (Dubai, Bangkok, Karachi, etc.) — this is Kit's native timezone picker.

## Key Decisions

### Decision: Cannot fix on our end
**Rationale**: The timezone list is controlled by Kit's platform. We don't have any settings JSON that defines the dropdown options — Kit provides the timezone picker as a built-in component.

### Decision: Request Kit add Brisbane
**Action**: Draft email to support@kit.com requesting they add Brisbane/Queensland to their timezone picker, explaining the DST difference from Sydney.

### Decision: Provide Sydney workaround to Sharon
**Workaround**: Sydney (GMT+10:00) works most of the year, but will be off by 1 hour during Sydney's DST months (Oct-Apr) when Sydney shifts to GMT+11 while Brisbane stays at GMT+10.
