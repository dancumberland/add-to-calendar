## Implementation Details
For non-midnight-UTC timestamps, the fix now takes `max(UTC date, target-TZ date)` instead of just the target-TZ date. This is mathematically correct for all three known Kit date picker modes:
- Same TZ (dates agree → max is identity)
- Browser behind UTC, different account TZ (Kirstin: UTC=Mar18, Pacific=Mar17 → max=Mar18 correct)
- Browser ahead of UTC, same account TZ (Brisbane: UTC=Feb4, Brisbane=Feb5 → max=Feb5 correct)

ISO date strings are lexicographically orderable, so simple `>` comparison works.
