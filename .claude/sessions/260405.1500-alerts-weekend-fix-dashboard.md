## Context
Following the earlier session that built the full observability system, three backlog items remained: the Monday test cron ran silently on failure, the weekly aggregation missed Saturday/Sunday data, and no dashboard existed for viewing usage trends.

## Objectives
1. Cron failure alerts — Slack notification when any test fails, listing which tests and why
2. Weekend data gap — fix `aggregateWeeklyData()` to include full Mon-Sun week
3. Metrics dashboard — visual admin page with Chart.js, protected by existing secret

## Implementation Details

### Cron Failure Alerts
Added `sendFailureAlert(results)` to `api/test-calendars/index.js`. Called after all tests run if `results.summary.failed > 0`. Posts to `SLACK_WEBHOOK_URL` with:
- Header: "🚨 Kit Calendar — Test Failures Detected"
- Bullet list of each failed test with its error messages
- Pass/total count and duration
- Dashboard link in context footer

### Weekend Data Gap Fix
Root cause: `aggregateWeeklyData()` defaulted to `DateTime.utc().endOf('week')` — the current (incomplete) week. When the weekly-report cron runs Friday, `endOf('week')` is the upcoming Sunday with no Sat/Sun data yet.

Fix: changed default target to `DateTime.utc().minus({ weeks: 1 })` so the aggregation always targets the last fully completed week. The `targetDate` parameter still works as before for manual backfills.

### Metrics Dashboard
New endpoint `api/dashboard/index.js`:
- Auth: `?secret=WEEKLY_REPORT_SECRET` query param
- Fetches `getTwelveWeekTrend()` + `getAllTimeStats()` in parallel
- Returns self-contained HTML — no build step, Chart.js from CDN
- 4 stat cards: this week, last week, WoW%, all-time total
- 12-week bar chart (current week highlighted blue, prior weeks dark)
- URL: `https://kit-app-build.vercel.app/api/dashboard?secret=ENCODED_SECRET`

### Dashboard Link in Slack
Added `<url|View Dashboard>` context block to both:
- Weekly report (`api/weekly-report/index.js`) — appears below the 8-week chart
- Failure alert (`api/test-calendars/index.js`) — appears in the context footer

Secret is URL-encoded via `encodeURIComponent()` before embedding in the link.

## Key Decisions

**Secret in URL**: Used `WEEKLY_REPORT_SECRET` for dashboard auth — same secret already used for the test endpoint and weekly report. No new env var needed.

**Self-contained HTML**: Dashboard returns HTML directly from the API function rather than a separate static file. Keeps the project structure simple (pure API, no public/ directory).

**Previous week targeting**: Changed the default aggregation target to last week rather than current week. The `targetDate` param still supports manual backfills for any specific week.
