## Context
User reported that calendar buttons marked as "centered" in Kit.com were showing as left-aligned in actual test emails. Additionally, two critical issues emerged during testing: button text was not visible and Outlook URLs were generating broken link errors.

## Objectives
1. Fix button centering in email clients (Gmail, Outlook, Apple Mail)
2. Resolve button text visibility issues
3. Fix Outlook calendar URL format errors
4. Clean up project files and optimize structure

## Implementation Details

### Button Alignment Fix
**Problem**: Used CSS flexbox (`display: flex; justify-content: center`) which isn't well-supported in email clients.

**Solution**: Replaced with email-compatible styling:
```javascript
// Before
const containerStyle = `display: flex; justify-content: ${alignment};`

// After  
const getAlignmentStyles = (align) => {
  switch (align) {
    case 'center': return `text-align: center; display: block;`;
    case 'left': return `text-align: left; display: block;`;
    case 'right': return `text-align: right; display: block;`;
  }
};
```

### Button Text Visibility Fix
**Problem**: Button text not rendering in Kit.com environment.

**Solution**: Enhanced CSS with multiple fallbacks:
```css
color: #FFFFFF !important;
-webkit-text-fill-color: #FFFFFF;
background-color: #4285F4;
background: #4285F4;
font-weight: normal;
line-height: 1.2;
border: none;
```

### Outlook URL Format Fix
**Problem**: Outlook used ISO datetime format causing broken links:
```
startdt=2025-09-05T11:00:00.000-07:00
```

**Solution**: Changed to UTC format matching Google Calendar:
```javascript
// Before
outlookUrl.searchParams.set("startdt", startDateTime.toISO());

// After
outlookUrl.searchParams.set("startdt", formatDateForGoogle(startDateTime));
```
